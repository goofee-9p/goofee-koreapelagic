# 디자인 시스템 — 코리아펠라직 지원 포트폴리오

이 문서는 **일관성 계약서**입니다. 마크업을 쓰기 전에 여기서 값을 찾고, 여기 없는 값은
하드코딩하지 않고 이 문서에 먼저 추가합니다.

- **원본** — `index.html` 하나. 웹사이트가 원본이고 PDF는 인쇄 스타일시트로 파생됩니다.
- **참고 대상** — 브랜드 무드는 [가시제거연구소](https://mackerel.co.kr) 실측.
  기존 포트폴리오(`claude share/portfolio`)에서는 **내용과 소재만** 가져오고
  레이아웃·디자인은 따르지 않습니다.

---

## 1. 브랜드 근거

mackerel.co.kr 을 브라우저로 열어 computed style 을 실측한 결과입니다.

| 항목 | 실측값 |
|---|---|
| 액센트 | `rgb(255,143,28)` = **`#FF8F1C`** — 배경으로만 60회 이상. 사실상 유일한 브랜드 컬러 |
| 텍스트 | `#000` · `rgb(53,53,53)` · `rgb(153,153,153)` |
| 면 | `#FFF` · `rgb(245,245,245)` · `rgb(222,222,222)` |
| 폰트 | **Pretendard Variable** |
| 라운드 | `20px` (72회) · **`20px 0` 비대칭 (47회)** · `50px` 알약 (12회) · `50%` 원형 |

**해석** — 이 브랜드의 "귀여움"은 일러스트나 파스텔이 아니라
**오렌지 + 큰 라운드 + 비대칭 코너** 세 가지입니다. 그래서 우리도 이 셋만 가져옵니다.

**무드 강도는 "중간 — 따뜻한 전문성"으로 확정.**
오렌지는 액센트·태그·밴드·진행바에만 쓰고 본문은 검정 계열을 유지합니다.
포트폴리오는 신뢰가 먼저입니다. 브랜드 결은 느껴지되 주인공은 수치와 근거입니다.

## 2. 색

### 2-1. 토큰

```css
:root{
  /* 브랜드 */
  --brand:        #FF8F1C;  /* 큰 면·태그·밴드·진행바 */
  --brand-ink:    #B85A05;  /* 흰 배경 위 오렌지 '텍스트' */
  --brand-mark:   #D2700A;  /* 흰 배경 위 얇은 마크·선·아이콘 */
  --brand-soft:   #FFF3E4;  /* 틴트 면 (약) */
  --brand-soft-2: #FFE7CC;  /* 틴트 면 (강) */

  /* 잉크 */
  --ink:    #191919;
  --ink-2:  #353535;
  --ink-3:  #767676;   /* 본문 색 하한 */
  --dim:    #999999;   /* 큰 글자·장식 전용 */

  /* 면·선 */
  --paper:     #FEFDFB;  /* 페이지 플레인 (아주 옅은 웜) */
  --surface:   #FFFFFF;  /* 카드 */
  --panel:     #F5F5F5;
  --line:      #E4E4E4;
  --mute-fill: #D4D6D9;  /* 비강조 채움 (before 막대) */
}
```

### 2-2. 대비 실측표 (WCAG, 계산값)

| 색 | vs `#FFF` | vs `#191919` | 쓸 수 있는 곳 |
|---|---|---|---|
| `--brand` `#FF8F1C` | **2.28** | 7.70 | 큰 면, 알약 태그, 밴드. **흰 배경 위 작은 텍스트 금지**. 어두운 면 위 텍스트는 가능 |
| `--brand-ink` `#B85A05` | **4.66** | 3.77 | 흰 배경 위 오렌지 본문 텍스트 (AA 통과) |
| `--brand-mark` `#D2700A` | **3.46** | 5.08 | 흰 배경 위 얇은 선·아이콘·큰 텍스트 (≥3:1) |
| `--ink` `#191919` | 17.58 | — | 제목·본문 |
| `--ink-2` `#353535` | 12.27 | — | 본문 |
| `--ink-3` `#767676` | **4.54** | — | 보조 텍스트 **하한** |
| `--dim` `#999999` | **2.85** | — | 24px 이상 큰 글자, 장식선. **캡션 본문에 쓰지 말 것** |

> 기존 포트폴리오는 12–13px 캡션에 `#a8a8a8`(2.3:1) 을 여럿 썼습니다. 화면에선 넘어가도
> 인쇄하면 읽히지 않습니다. 이번에는 **캡션 최소 13px / `--ink-3`** 를 지킵니다.

### 2-3. 브랜드 아이덴티티 색 (데이터 색 아님)

| 브랜드 | 색 | 용도 |
|---|---|---|
| 지누스 | `#0E5B44` | 로고 옆 타임라인 막대, 섹션 라벨 |
| 샤크닌자 | `#141414` | 〃 |
| F&F 디스커버리 | `#1B3560` | 〃 |

**이 세 색을 차트 계열색으로 쓰지 않습니다.** dataviz 검증기에 4색(브랜드 오렌지 포함)을
categorical 팔레트로 넣어보면 명도대·채도 하한·정상시야 분리가 전부 FAIL 합니다
(`#0E5B44`↔`#1B3560` 정상시야 ΔE 14.7 — 15 미만). 아이덴티티와 데이터는 역할이 다릅니다.

## 3. 차트 규칙

이 사이트의 차트는 거의 전부 **"이 숫자가 올랐다"** 가 요지입니다.
그러면 정답은 categorical 이 아니라 **emphasis** — 하나만 브랜드색, 나머지는 회색입니다.

### 하면 안 되는 것

- 이중 축(y축 2개) — 단위가 다르면 차트를 나누거나 공통 기준으로 지수화
- 시리즈 색 돌려쓰기, 9번째 색 만들어내기
- 무지개 램프, 발산 팔레트 중간에 색상 넣기
- 모든 데이터 점에 숫자 달기
- 계열색을 텍스트에 쓰기 — 값·라벨·범례는 잉크 토큰, 색은 옆의 마크가 담당

### before → after

`--mute-fill` (before) + `--brand` (after). **값은 항상 막대 위 직접 라벨.**
브랜드 오렌지가 흰 배경에서 3:1 미만이라 relief rule 상 라벨이 선택이 아니라 **의무**입니다.

### 퍼널·단계 (오디널 램프)

단일 색상, 밝음 → 어두움. dataviz 검증기 **전 항목 PASS** 조합:

```
#F2A340  →  #E5850F  →  #BC6605  →  #8F4C03  →  #6B3802
```

(단일 색상 스프레드 10°, 인접 ΔL 전부 ≥0.06, 밝은 끝 대비 2.08:1 ≥ 2:1)

### 마크 사양

- 막대 데이터 끝 4px 라운드, 베이스라인에 붙임
- 선 2px, 마커 ≥8px
- 인접 채움 사이 2px 면색 간격
- 그리드·축은 뒤로 물러남 (`--line`, 1px)
- 2계열 이상이면 범례 필수, 4계열 이하는 직접 라벨도 병기

## 4. 레이아웃

### 4-1. 골격

```
콘텐츠 최대폭   1440px
좌우 여백       clamp(24px, 5vw, 96px)
컬럼            12 / 거터 28px   (768 아래 4컬럼)
섹션 상하 여백  clamp(72px, 9vw, 160px)
```

- **Split 의 결과 컬럼은 `sticky`** (901px 이상). 과정(좌)이 결과(우)보다 길 때 결과가
  시야에서 사라지지 않게 붙여 둡니다. 우측이 더 길면 아무 일도 하지 않습니다.
  좌우 높이차가 **400px 넘게** 벌어지면 sticky 로 덮지 말고 내용을 옮겨 균형을 잡습니다.
- **섹션은 스크롤 단위**입니다. 고정 높이가 아니라 `min-height` 기준으로 내용만큼 늘어납니다.
- 페이지 표시는 좌측 세로 스파인이 아니라 **고정 상단바 + 상단 2px 진행 레일**입니다.
- 플레인은 순백이 아니라 `--paper` `#FEFDFB`. 그 위에 흰 카드가 떠 보입니다.

### 4-2. 브레이크포인트

| 폭 | 처리 |
|---|---|
| ≥1440 | 기준 레이아웃 |
| 1024–1439 | 컬럼 폭만 축소, 구조 유지 |
| 768–1023 | Split 2단 → 비율 완화, 소재 월 5열 → 3열 |
| <768 | 전부 1단, 소재 월 2열, 상단바 앵커는 접음 |

### 4-3. 간격 스케일 (8px 기반)

`4 · 8 · 12 · 16 · 24 · 32 · 40 · 56 · 72 · 96 · 128 · 160`

여기 없는 값은 쓰지 않습니다.

### 4-4. 라운드

| 토큰 | 값 | 용도 |
|---|---|---|
| `--r-sm` | `8px` | 태그, 작은 칩 |
| `--r` | `20px` | 카드 기본 |
| `--r-asym` | `20px 0` | **시그니처.** 섹션당 최대 1–2개, 강조 카드에만 |
| `--r-pill` | `999px` | 알약 라벨, 버튼 |
| `--r-full` | `50%` | 프로필 원형 |

> 비대칭 코너는 아껴 써야 효과가 납니다. 모든 카드에 걸면 그냥 노이즈가 됩니다.

## 5. 타이포

`Pretendard Variable` (브랜드 사이트와 동일) → `Pretendard` → `Apple SD Gothic Neo` → `sans-serif`

| 역할 | 크기 | 굵기 | 행간 | 자간 |
|---|---|---|---|---|
| display | `clamp(56px, 9vw, 168px)` | 800 | 0.95 | -0.05em |
| h1 | `clamp(34px, 4.4vw, 68px)` | 800 | 1.12 | -0.04em |
| h2 | `clamp(26px, 2.6vw, 42px)` | 700 | 1.2 | -0.035em |
| h3 | `clamp(20px, 1.8vw, 28px)` | 700 | 1.3 | -0.03em |
| lead | `clamp(17px, 1.4vw, 22px)` | 400 | 1.65 | -0.015em |
| body | `17px` | 400 | 1.6 | -0.01em |
| small | `15px` | 400 | 1.6 | 0 |
| caption | `13px` | 400 | 1.55 | 0 |
| label | `11px` | 700 | 1.3 | **0.22em**, 대문자 |

**공통 규칙**

- `word-break: keep-all` — 한글 단어가 중간에서 끊기지 않게
- 숫자가 세로로 정렬돼야 하는 표·축에만 `font-variant-numeric: tabular-nums`
- 본문 한 줄 최대 **72자**. 넘으면 컬럼을 좁힙니다
- **본문 글자 수를 기존 포트폴리오 대비 40% 줄입니다.** 밀도를 낮추는 게 리디자인의 절반입니다

## 7. 컴포넌트

### 상단바 `.topbar`
고정. 이름 · 섹션 앵커 · PDF 버튼. 스크롤 시 높이 72 → 56px, 배경 반투명 + `backdrop-filter`.
768 아래에서 앵커는 숨기고 이름과 PDF만 남깁니다. **인쇄 시 숨김.**

### 진행 레일 `.rail`
상단 2px, `--brand`. 스크롤 비율. **인쇄 시 숨김.**

### 영상 카드 `.vcard` (신규)
```
.vcard          래퍼. aspect-ratio 로 규격 고정 (9/16, 1/1, 16/9)
.vcard video    poster 필수. muted loop playsinline preload="metadata"
.vcard .spec    우상단 규격 배지 (알약, --brand-soft-2 / --brand-ink)
.vcard .cap     하단 캡션 (13px, --ink-3)
```
- **poster 는 필수입니다.** 인쇄와 JS 미실행 시 이 이미지가 그대로 나갑니다
- `muted` + `playsinline` + `loop` — 자동재생 정책에 걸리지 않는 조합입니다
- 자동재생은 뷰포트 진입 시에만(`IntersectionObserver`, threshold 0.25). 이탈하면 `pause()`
- **탭을 떠났다 돌아오면** 브라우저가 재생을 멈춰 둡니다. 교차 이벤트는 새로 안 생기므로
  `visibilitychange` 에서 화면 안 영상을 직접 되살립니다
- 컨트롤은 숨기되 클릭하면 재생/정지 토글
- 규격 배지는 **영상 위가 아니라 캡션에** (`.vspec`) — 소재를 가리지 않기 위해서입니다

### 스탯 타일 `.stat`
큰 수치 + 단위 + 한 줄 설명. 수치는 `clamp(40px, 4vw, 64px)` / 800.
카운트업 대상이므로 `tabular-nums` 로 폭을 고정해 레이아웃이 흔들리지 않게 합니다.

### 프로세스 레일 `.flow`
4단계 흐름. **네모 상자를 쓰지 않습니다.** 하나로 이어진 2px 선 위에 단계마다 점을 찍고,
그 아래 라벨 · 제목 · 설명을 둡니다. 강조 단계(`.on`)는 선과 점을 `--brand` 로 바꾸고
라벨·제목을 `--brand-ink` 로 올립니다.

> 처음에는 검은 채움 박스를 썼는데, 모바일에서 카드가 세로로 쌓이니 답답하고 싸 보였습니다.
> 상자를 걷어내니 단계가 '흐름'으로 읽힙니다. **강조는 면이 아니라 색으로만** 합니다.

### 소재 월 `.wall`
정사각 타일 그리드. 5열 → 3열 → 2열. `gap: 12px`, 타일 `--r-sm`.
크롭이 생기지 않게 원본 비율(1:1)과 타일 비율을 맞춥니다.
**16:9 소재를 1:1 타일에 넣지 마세요** — 카피가 잘립니다.

### 소재 아카이브 `.arch`
브랜드별로 묶어 보여주는 큰 그리드. 좌측 라벨 컬럼(200px, `sticky`) + 5열 타일.
브랜드당 10종으로 맞춰 2행이 정확히 채워지게 합니다 — 마지막 줄이 비면 미완성으로 보입니다.
인쇄에서는 라벨을 위로 빼고 그리드가 지면을 다 쓰게 해 **브랜드 한 곳이 한 장**을 차지합니다.

### 영상 행 `.vrow`
규격이 다른 영상을 **같은 높이로** 세우는 행. `flex` + `wrap` 은 캡션 길이에 따라 폭이 흔들려
마지막 칸이 다음 줄로 떨어졌습니다. **컬럼 비율을 비율값으로 못박으면** 높이가 저절로 맞고 줄바꿈도 없습니다.

| 변형 | 컬럼 | 쓰는 곳 |
|---|---|---|
| `.vrow--mix` | `0.5625fr 1fr 1fr` | 9:16 하나 + 1:1 둘 (9÷16 = 0.5625) |
| `.vrow--v3` / `--v4` | `repeat(3\|4, 1fr)` | 세로 영상만 나열 |

### 재배분 도식 `.rda`
공유예산처럼 **한 덩어리를 나눠 쓰는 구조**를 보여줄 때. 네모 두 개를 화살표로 잇지 않습니다.
하나의 트랙을 경계선(`.seam`)으로 가르고, 그 경계가 오른쪽으로 밀린다는 걸 손잡이로 표시합니다.
아래 점선(`.rda-return`)이 "다시 측정해 기준을 갱신"하는 루프입니다.
**경계 위치는 5:5 고정** — 비율을 다르게 그리면 없는 데이터를 주장하게 됩니다.

### 소재 카드 `.card--img`
설명만 있는 상자 대신 **근거가 되는 소재를 머리에 얹은 카드**. 이미지 1:1 → 본문 → 인용(`.q`).
카피 축처럼 "말한 것"과 "실제 소재"가 붙어야 하는 곳에 씁니다.

### 태그 `.tag`
알약. `--brand-soft` 배경 + `--brand-ink` 텍스트. 11px label 스케일.

### 그 외

## 8. 모션

**원칙 — 스크롤을 방해하지 않는다.** 패럴랙스 남용·스크롤재킹·회전·바운스는 넣지 않습니다.
전부 `IntersectionObserver` 하나로 처리하고 **한 번만 실행**합니다(재진입 반복 없음).

| 모션 | 대상 | 사양 |
|---|---|---|
| 진입 페이드업 | 섹션 헤더·카드 | `opacity 0→1`, `translateY 20px→0`, 480ms, 자식 60ms 스태거 |
| 막대 성장 | 차트 막대·타임라인 | `width/height 0→값`, 700ms `cubic-bezier(.22,1,.36,1)` |
| 숫자 카운트업 | 스탯 타일 | 900ms, `tabular-nums` |
| 영상 자동재생 | 영상 카드 | 진입 시 `play()`, 이탈 시 `pause()` |
| 진행 레일 | 상단 2px | 스크롤 비율 |

`prefers-reduced-motion: reduce` 면 **전부 끕니다.**

### PDF 안전장치 3중

1. 모션 CSS 는 전부 `@media screen` 안에만 둡니다
2. `@media print { *{ animation:none!important; transition:none!important;
   opacity:1!important; transform:none!important } }`
3. **초기 상태를 JS 가 `.motion` 클래스로 덧씌우는 방식(additive).**
   JS 가 안 돌면 모든 요소가 처음부터 최종 상태입니다

> 3번이 핵심입니다. "숨겼다가 JS 로 보여주는" 방향이면 JS 실패 시 빈 페이지가 나옵니다.
> 반대 방향으로 만듭니다.

## 9. 인쇄 (PDF 파생)

```css
@page { size: 1920px 1080px; margin: 0 }
```

- 상단바·진행 레일·앵커·스크롤 힌트 숨김

- 2단 레이아웃은 인쇄에서도 유지 (모바일 1단으로 접히지 않게 `@media print` 에서 폭 고정)

- 출력: Chrome headless `--print-to-pdf`, `Start-Process -Wait`, 경로 공백은 `%20`

## 10. 카피 원칙

**디자인만큼 중요한 축입니다.** 제목·리드문·캡션·이력서 문장 전부 여기 따릅니다.

### 하지 않을 것

- 과장 형용사 — "혁신적", "압도적", "극대화", "탁월한", "성공적으로"
- 자기 홍보 문구 — "~를 통해 성과를 창출했습니다", "적극적으로 리드했습니다"
- AI 문체 — 모든 불릿이 같은 길이·같은 동사꼴, 과한 병렬 구조, "~함으로써"
- 근거 없는 수식 — 숫자가 없으면 형용사로 메우지 않고 그냥 뺍니다

### 할 것

- **결론 먼저, 근거 뒤** — "월 6억을 굴렸습니다" 다음에 "패션, 약 1년"
- **문장 길이를 일부러 흔든다** — 긴 문장 옆에 짧은 문장 하나를 툭
- **담백한 동사** — 만들었습니다 / 바꿨습니다 / 남겼습니다 / 없앴습니다
- **고유명사와 숫자가 형용사를 대체한다** — "많은 소재"가 아니라 "1:1·9:16·16:9 세 규격"
- **기여도를 정직하게** — "기획 참여 · 디자인팀 협업 제작", "기여도 50%"
- **화면에 보이는 것과 문장이 어긋나지 않게** — "혜택을 먼저"라고 썼으면 옆 소재에 할인율이 보여야 합니다
- **같은 수치를 두 곳에서 반복하지 않기** — 근거(차트)가 있는 쪽에만 두고 다른 곳은 링크로 넘깁니다
- **가진 것보다 크게 말하지 않기** — 열 점만 골랐으면 "2년간 만든 소재"가 아니라 "제작 대표 소재"

### 톤 기준선

> "스스로 질문하고, 개선점을 찾고, 효율적으로 실행합니다."
> "이긴 것은 상시 운영으로 올리고 진 것은 제외 액션으로 확정해, 판단을 계정에 남겼습니다."
